# October 2026 Reflections

Beginning in October, each person writes one report for each consecutive 14-day period and divides it into two dated weeks. The first report covers October 1–14 (October 1–7 and October 8–14); the second covers October 15–28. Start the next period October 29 and file it under November, the month in which it ends.

Use `docs/templates/biweekly-reflection-template.md`. Name the file for the period's end date, for example `2026-10-14-rafi.md`. A report started before the period ends should state through which date it is current and should not claim future work is complete.
